Deploy
Put index.html at the project root. For Cloudflare Pages with no build step, use an empty build command and the root directory as the output directory (or follow the current Pages dashboard options). For GitHub Pages, push these files to a repository and enable Pages.

Important
The marketplace listings are stored in each visitor's browser using localStorage. A shared online marketplace requires a backend/database. The contact form opens the visitor's email client; a form backend is required for server-side storage.
